Privacy Policy

1. Zero Data Collection

Hum aapki koi bhi personal file ya image server par upload nahi karte. ProToolkit ka saara logic client-side (aapke browser mein) chalta hai. Iska matlab hai ki aapka data aapke device se bahar kabhi jata hi nahi.

2. Browser-Based Storage

Agar hum koi settings save karte hain, toh wo kewal aapke browser ke cache mein hoti hain. Hum koi cookies ya tracking pixels ka upyog marketing ke liye nahi karte.

3. Security Guarantee

Kyunki processing offline-like environment mein hoti hai, internet par data leak hone ka khatra 0% hai. Aap bina kisi dar ke sensitive documents process kar sakte hain.
